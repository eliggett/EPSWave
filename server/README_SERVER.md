# Server

There is a server included here for testing. The server launches an https server from the current working directory. Start it from the directory the index.html file is inside. 

The server uses keys generated by the gen_keys.sh command. These are good enough for LAN testing. 

Firefox will refuse to work with midi over https if the keys are not blessed by the https ssl people. So, you'll need to use chrome or chromium. 

Example:

```bash
cd EnsoniqEPS16Plus
python3 server/server.py
```

It's not meant for production -- this is just a very simple server to aid in development.
